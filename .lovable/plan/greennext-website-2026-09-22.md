# GreenNext Website

## Goal

Build a polished, responsive GreenNext website that immediately communicates AI-ready data center infrastructure, energy efficiency, intelligent automation, and a South India regional network.

## Experience

- Create a light, premium infrastructure aesthetic using deep green, emerald, and restrained technology accents.
- Use clean technical typography, high-quality data-center imagery, precise diagrams, and restrained motion.
- Keep every metric and operational state explicitly labeled as illustrative where real data is unavailable.

## Page Structure

1. Immersive infrastructure hero with two calls to action and four capability indicators.
2. Four-part “Why GreenNext” overview.
3. Animated AI infrastructure flow diagram.
4. Interactive energy relationship dashboard.
5. Intelligent automation workflow and conceptual scenarios.
6. Interactive South India regional network for Madurai, Coimbatore, Trichy, and Mangalore.
7. Layered infrastructure architecture with moving operational signals.
8. Factual sustainability principles.
9. Region-selectable illustrative infrastructure dashboard.
10. Understand → Intelligence → Optimize operating model.
11. Final contact call to action and concise footer.

## Interaction and Accessibility

- Add working section navigation, calls to action, region selectors, map focus states, and dashboard switching.
- Use restrained scroll reveals and signal animations with reduced-motion support.
- Ensure keyboard navigation, visible focus states, meaningful labels, strong contrast, and responsive layouts.

## Technical Details

- Build the page at `/` using the existing TanStack Start structure.
- Define the full semantic color, typography, radius, shadow, and animation system in the global stylesheet.
- Generate and bundle a purpose-made data-center hero image rather than using a remote placeholder.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Validate the final page at desktop and mobile sizes and check the current build diagnostics.
